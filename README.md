# 📑 Auto Loan Document Optimizer & Renamer (ระบบจัดการเอกสารสินเชื่อสาขา)

เว็บแอปพลิเคชันจัดการชื่อและแปลงไฟล์เอกสารสินเชื่ออัตโนมัติตาม Checklist ทั้ง 5 หมวด ออกแบบสไตล์ **Accessible True Neumorphism (Soft UI)** สีส้ม-ขาว-ดำ พร้อมระบบบีบอัดไฟล์ภาพไม่ให้เกิน **5MB** และดาวน์โหลดรวมเป็น **.ZIP** ได้ในคลิกเดียว

---

## 🌟 ฟีเจอร์เด่น (Key Features)
- **100% Client-Side:** ทำงานบนเบราว์เซอร์ในเครื่องทั้งหมด ไม่มีการส่งไฟล์ออกภายนอก ปลอดภัย รวดเร็ว
- **ครบทั้ง 5 หมวดสินเชื่อ:**
  1. 🏠 สินเชื่อที่ดิน (48 รายการ)
  2. 🏍️ สินเชื่อรถจักรยานยนต์ (39 รายการ)
  3. 🚛 สินเชื่อรถบรรทุก (47 รายการ)
  4. 🚗 สินเชื่อรถเก๋ง / กระบะ / รถตู้ (45 รายการ)
  5. 🚜 สินเชื่อรถเพื่อการเกษตร (46 รายการ)
- **แปลงไฟล์ & คุมขนาดอัตโนมัติ:**
  - กำหนดนามสกุล (PDF / JPG) ตามมาตรฐานของสินเชื่อนั้นๆ
  - ย่อและบีบอัดรูปภาพให้ขนาดไม่เกิน **5MB** โดยรักษาความคมชัดสูงสุด
  - รองรับการหมุนภาพ (90° Rotation)
- **การสั่งการแบบ Batch:**
  - ⚡ เรียงตาม Checklist อัตโนมัติ
  - 📄 แปลงทั้งหมดเป็น .PDF
  - 🖼️ แปลงทั้งหมดเป็น .JPG
  - 📦 ดาวน์โหลดเอกสารทั้งหมดเป็นไฟล์ **.ZIP** พร้อมสรุปขนาดไฟล์ก่อนดาวน์โหลด
- **UI/UX True Neumorphism (Soft UI):**
  - ดีไซน์นุ่มนวลแบบ 3D Soft Clay Extrusion
  - คอนทราสต์สูง ตัวหนังสือคมชัดตามมาตรฐานสากล

---

## 🚀 วิธีเปิดใช้งาน
เพียงเปิดไฟล์ `index.html` บนเบราว์เซอร์ (Google Chrome, Microsoft Edge, Safari ฯลฯ) สามารถใช้งานได้ทันทีโดยไม่ต้องติดตั้งโปรแกรมเสริม

---

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)
- **HTML5 & Vanilla JavaScript**
- **Tailwind CSS** (Soft Neumorphic Tokens)
- **PDF-LIB** (แปลงภาพเป็นเอกสาร PDF ความคมชัดสูง)
- **JSZip** (รวมไฟล์และสร้าง .ZIP ในเครื่อง)
- **Lucide Icons**
